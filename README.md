# MikroMakro

Lokaler Makro-Rekorder für das eigene Android-Handy (Doogee M30, Android 8 bis 16).
Nimmt Tippen, Wischen und Schreiben auf und spielt denselben Ablauf wieder ab.
Alles bleibt auf dem Gerät. Kein Netz, kein Konto, kein Root.

## Download

[MikroMakro.apk](https://github.com/DerPoser/MikroMakro/releases/download/v1.0.0/MikroMakro.apk)

Die gleiche Datei liegt auch unter `apk/MikroMakro.apk`.

## Einrichten

1. APK installieren. Unbekannte Apps für den Browser einmal erlauben.
2. MikroMakro öffnen und die Bedienungshilfe einschalten.
3. Ist der Schalter grau: Einstellungen → Apps → MikroMakro → Menü → Eingeschränkte Einstellungen zulassen.
4. Akku-Optimierung aus. Auf dem Doogee zusätzlich Autostart erlauben, falls vorhanden.
5. Ziel-App öffnen, auf der schwebenden Leiste REC tippen.
6. STOP speichert. PLAY spielt ab. HALT bricht ab.

Hardware-Tasten nimmt Android ohne Root nicht auf. Zurück und Home sitzen auf der Leiste.
Passwortfelder werden nicht gespeichert.
